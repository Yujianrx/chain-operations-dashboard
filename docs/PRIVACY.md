# 隐私与发布范围

公开内容仅包含功能代码、许可、地理资源、空数据模板和项目文档。

未包含企业品牌名称及图片、真实门店/会员/活动记录、经营数值、生产截图、源数据库账号密码、私有 JSON、SQLite、身份盐、运行日志或本机验收材料。没有复制已安装系统的业务数据库。

所有业务数组在 `public/data/template.json` 中为空；`tests/fixtures/` 为程序人工构造的测试输入，不对页面提供业务数据。`npm run check:public` 用于检查公共目录和空模板。

`.gitignore` 排除 `.env.local`、`.local-data/`、数据库文件、日志、私有 JSON、上传文件、截图证据和备份。后续使用者需在提交前再次检查暂存文件；忽略规则不会自动清除曾经提交到 Git 历史的文件。
